## ✨ Fonctionnalités

### 🔒 Verrouillage de cartes
Verrouille tes cartes précieuses pour ne plus jamais les défausser ou les vendre par erreur.

### ⌨️ Ouverture de boosters au clavier
Ouvre tes boosters rapidement avec des raccourcis clavier, sans enchaîner les clics.

### 🏷️ Système d'étiquettes amélioré
Organise ta collection avec un système d'étiquettes plus complet et plus pratique que celui de base.

### 🎨 Personnalisation esthétique
- Change l'image de tes cartes
- Passe tes cartes en **fullart**
- Ajoute des **effets visuels**
- Et bien plus encore

### Installation manuelle
1. Télécharge la dernière version dans l'onglet [Releases](../../releases).
2. Décompresse l'archive.
3. Ouvre `chrome://extensions` (ou `about:debugging` sur Firefox).
4. Active le **mode développeur**.
5. Clique sur **Charger l'extension non empaquetée** et sélectionne le dossier décompressé.

## 🚀 Utilisation

1. Rends-toi sur le site de Wiki Master.
2. WikiTools+ s'active automatiquement.
3. Clique sur l'icône de l'extension pour accéder aux réglages.

### ⌨️ Raccourcis clavier

| Action | Raccourci |
|---|---|
| Ouvrir un booster | `À définir` |
| Verrouiller / déverrouiller une carte | `À définir` |

## 🛠️ Développement

```bash
git clone https://github.com/TON_PSEUDO/wikitools.git
cd wikitools
```

Charge ensuite le dossier du projet comme extension non empaquetée (voir *Installation manuelle*).
